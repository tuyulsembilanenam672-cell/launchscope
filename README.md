LaunchScope ranks 198 pre-token protocols by implied value, from a sealed DefiLlama snapshot: TVL, 7-day growth and age with no token, never a hardcoded list of names. Every row carries a concrete 7-step farm plan with costs and time, and the dashboard is a sortable, filterable board with a detail view per protocol and a live-token view set apart.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```

`snapshot.json` is the sealed snapshot the kit ships (758 protocols as of 2026-11-14). Node 22.18 or later, standard library only, no network.
